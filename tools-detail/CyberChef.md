# CyberChef Detail Guide
> "The Cyber Swiss Army Knife". Tool berbasis web untuk manipulasi data tanpa coding.

## Cara Menggunakan
1. Buka [CyberChef](https://gchq.github.io/CyberChef/) (Bisa dijalankan offline).
2. Drag & Drop "Operations" ke kolom **Recipe**.
3. Masukkan data ke kolom **Input**.
4. Hasil akan muncul otomatis di kolom **Output**.

## Recipe Favorit
- **Magic:** Mencoba menebak encoding data secara otomatis.
- **From Base64 / To Base64:** Konversi teks biasa ke/dari Base64.
- **URL Decode:** Membersihkan karakter persen (seperti `%20` menjadi spasi).
- **Find / Replace:** Manipulasi string cepat.
- **XOR:** Berguna untuk tantangan kriptografi sederhana.
- **Extract IP / Email:** Mengambil informasi spesifik dari tumpukan data teks.
